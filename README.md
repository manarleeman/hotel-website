🏨 Hotel Website – Mobile Version

This project is a mobile-first hotel booking website built with HTML, CSS, and JavaScript. It was created by following a Figma design to practice design interpretation and responsive development.

The website focuses on a smooth mobile experience. It includes an interactive hamburger menu that slides in and out for easy navigation, and different sections such as Special Offers, Reviews, and Recent Posts, all of which are rendered dynamically using JavaScript. The reviews section displays three customer reviews arranged vertically to match the mobile design, while the “Why Choose Us” section highlights the hotel’s unique selling points.

The site has been deployed on Render.com, making it publicly accessible. A full walkthrough of the project is also available in the Loom recording where I explain the code structure, styling, and functionality.

⚙️ Setup

To run the project locally:

Clone the repository from GitHub.

Open index.html in your browser.

You can also edit script.js to change the dynamic content or update style.css to adjust the design.
